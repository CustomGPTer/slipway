# Slipway

Slipway installs APK, XAPK, APKS, APKM and ZIP files on Android with a safety report before every install: a red, amber or green verdict, permissions in plain English, signature, compatibility and tracker checks. Revision-aware library, install queue, history and clean-up. No internet access, no adverts, no account.

Website: https://customgpter.github.io/slipway/

Download: https://github.com/CustomGPTer/slipway/releases/latest/download/Slipway.apk
